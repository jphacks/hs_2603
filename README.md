# かんたん動画エディタ

[![IMAGE ALT TEXT HERE](https://jphacks.com/wp-content/uploads/2026/07/IMG_5316.png)](https://www.youtube.com/watch?v=piaNsc6ilBI)

Windows 向けの動画編集アプリです。動画や写真を並べて、テキストや BGM を入れ、MP4 に書き出せます。C++（Qt 6）と FFmpeg で作っていて、インターネットにつながなくても使えます（AI アシスタントを使うときだけ、AI サーバーに接続します）。AI サーバー（`server/`）を家の PC などで動かすと、アカウントごとに AI を使える量や考える深さを、ブラウザーの管理画面で決められます。アプリに API キーは要りません。

## 製品概要
### 背景(製品開発のきっかけ、課題等）
### 製品説明（具体的な製品の説明）
動画を読み込んで並べ、テキストや BGM を足して MP4 に書き出すまでを、1 つの画面で行える Windows 用の動画編集アプリです。左にメディアの一覧、中央にプレビュー、右に選んだものの設定、下にタイムラインがあります。

### 特長
#### 1. 並べるだけで形になる
読み込んだ動画や写真は、順番にタイムラインに並びます。縦長の動画を横長の画面に入れるときなど、縦横比が合わない素材は自動で「ぼかし背景」になります。
#### 2. テロップと BGM がすぐ入る
8 種類のスタイルから選び、プレビュー上でドラッグして置くだけでテロップが入ります。BGM は波形を見ながら配置でき、「動画の長さに合わせる」で長さもそろえられます。
#### 3. プレビューと同じ見た目で書き出す
色のフィルター、ぼかし背景、テキストは、プレビューと書き出しで同じ計算をしています。縦長（9:16）、正方形（1:1）、4:5、4K での書き出しにも対応しています。

## インストールと起動

1. [Releases](https://github.com/witchcrafttwo/e-editor/releases) の最新版から、`kantan-video-editor-cpp-<バージョン>-setup.exe` をダウンロードします。
2. ダウンロードした setup.exe を開き、インストール先を選んで「インストール」を押します。管理者権限はいりません。
3. スタートメニューかデスクトップの「かんたん動画エディタ」から起動します。`.kvproj`（プロジェクト ファイル）をダブルクリックしても開けます。

- 署名していないので、開くと SmartScreen の警告（「Windows によって PC が保護されました」）が出ることがあります。「詳細情報」→「実行」で進めます。
- FFmpeg やフォントもアプリと一緒に入ります。ほかに入れておくものはありません。
- 標準のインストール先は `%LOCALAPPDATA%\Programs\kantan-video-editor-cpp\` です。
- 新しい版にするときは、新しい setup.exe をそのまま実行します（上書きしてインストールします。プロジェクトや設定は残ります）。
- アンインストールは、Windows の「設定」→「アプリ」→「インストールされているアプリ」で「かんたん動画エディタ (C++版)」を選びます。
- 起動するとログインの画面が出ます。AI アシスタントを使うときはログインし、使わないときは「ログインしないで使う」で閉じます（[AI を使う準備](#ai-を使う準備)）。
- ソースからビルドして動かすときは、[開発の始め方](#開発の始め方) を見てください。

### 動作環境

- Windows 10 / 11（64 ビット）。動作確認は Windows 11 で行っています。
- 空き容量 約 230MB

## 使い方

1. 「メディアを追加」を押すか、ファイルをウィンドウにドラッグして読み込みます。動画と写真はビデオトラックの後ろに順番に並び、音楽はオーディオトラックに入ります。
2. タイムラインでクリップを選ぶと、右側で速度・音量・表示方法・フィルター・フェードを変えられます。
3. 左の「テキスト」タブのスタイルを、タイムラインの好きな位置へドラッグして落とすと、その時間にテロップが入ります（クリックだけでは追加されません。ドラッグ中に Esc で中止できます）。「テキスト」ボタンや T キーでも、再生位置に追加できます。文字は右側の入力欄で変え、位置はプレビュー上でドラッグして決めます。
4. 「書き出し」で解像度と品質を選び、MP4 に保存します。

### できること

- タイムライン: クリップをドラッグして並べ替え、端をドラッグして長さを調整、再生位置で分割、複製、削除。テキストとオーディオは好きな位置に置けて、重ねることもできます。テキストやオーディオ、再生位置をドラッグすると、キリのいい秒（目盛りの数字）やほかの端に吸い付きます。Alt を押しながらドラッグすると吸い付きません。
  - ドラッグ中の自動スクロール: クリップ・テキスト・オーディオの移動や長さの調整、再生位置の赤い線（目盛りや空いたところ）のドラッグ、音量キーフレームの点の移動、素材一覧からのドラッグ＆ドロップの途中で、マウスが時間の表示領域の左右の端から約 50px 以内に入ると、タイムラインが自動で横にスクロールします（端に近いほど速く、約 50px で低速、30px で中速、15px で高速。マウスを止めていても、端にいる間は続きます）。ウィンドウが画面からはみ出していて表示領域の端が画面の外にあるときは、画面の端で反応します。中央へ戻す・ボタンを離すと止まります。ドラッグしているものはカーソルに付いてくるので、表示されていない時間へも運べます（テキストやオーディオは、移動した先まで表示が広がります。0 秒より前には置けません）。ドラッグ中に Esc を押すと、やめて元の位置・長さに戻ります。
- クリップ: 速度（0.25〜4 倍）、音量（0〜100%。100% が元の音量）とミュート、表示方法（全体表示 / 拡大 / ぼかし背景）、フィルター 9 種類と明るさ・コントラスト・彩度・色温度の調整、フェードイン / アウト、写真の表示時間（0.5〜20 秒）。画面と縦横比が違う素材は、はじめから「ぼかし背景」になります。
- テキスト: スタイル 8 種類（シンプル、太フチ、バラエティ、字幕、タイトル、ポップ、メモ、インパクト）、フォント 7 種類、サイズ、太字、影、文字色・縁取り・背景、位置（上部 / 中央 / 下部）と揃え、字間、表示する時間、アニメーション（なし / フェード / スライド）。
- 文字をプレビューで直接編集: プレビューの文字を 1 回クリックすると選択（ドラッグで移動、四隅で拡大・縮小、上の丸で回転）、ダブルクリックするとその場で文字を入力・修正できます（枠が青くなり、入力位置の縦線が点滅します）。右の設定欄の入力欄からも、これまでどおり編集でき、どちらの編集も同じ文字データなので、すぐ反映し合います。
  - 編集中: 文字をそのまま入力（日本語入力にも対応。変換中の文字には下線が付き、変換の候補は入力位置のすぐ下に出ます）。Enter か Shift+Enter で改行、Backspace / Delete で削除、矢印・Home・End で入力位置を動かし（Shift を押すと範囲選択、Ctrl を押すと単語ごと）、マウスのクリックで入力位置を置き、ドラッグで範囲を選べます（ダブルクリックで単語）。Ctrl+A で全選択、Ctrl+C / X / V でコピー・切り取り・貼り付け、Ctrl+Z / Ctrl+Y で入力の取り消し・やり直しができます。
  - 終わり方: Ctrl+Enter か、文字の外側をクリックすると確定します。Esc で取り消すと、編集を始める前の文字に戻り、履歴にも残りません。再生を始めたとき・別のものを選んだとき・編集場所（タブ）を切り替えたときも、そこまでの入力を確定して終わります。確定までの入力は、元に戻す履歴の 1 回分（Ctrl+Z 1 回で編集前に戻ります）。編集中は、文字を動かしたりハンドルで変えたりはできません。
  - 文字の内容だけが変わり、フォント・サイズ・色・縁取り・影・背景・字間・揃え・不透明度・回転・拡大率・キーフレーム・表示する時間・段はそのままです。入力位置や選択範囲、枠は編集用の表示で、書き出しの動画にも全画面表示にも出ません。
- 字間（文字と文字の間隔）: 右の設定欄の「フォント」の、サイズの下にある「字間」で、-50〜100px の範囲で調整できます（はじめは 0 で、フォント本来の間隔です。プラスで広がり、マイナスで狭まります）。スライダーを動かすか、右の数値欄に直接入力します。数値欄にカーソルを合わせてホイールを回すか、数値欄をクリックして矢印キーを押しても調整できます（↑ → で増、↓ ← で減。1px ずつ、Shift で 10px ずつ、Alt で 0.1px ずつ）。変更はプレビューにすぐ反映され、選んでいる文字だけに適用されます。日本語・英語・数字・記号、複数行の文字に対応し、中央揃え・左揃え・右揃えもそのまま保たれます。字間は基準解像度（16:9 なら 1920×1080）のピクセルで、書き出しでも同じ見た目になります。
  - 字間の右の ◆ を押すと、再生位置に字間のキーフレームを置けます（◀ ▶ で前後のキーフレームへ）。たとえば 0 秒で 0px、1 秒で 20px、2 秒で 40px に置くと、文字の間隔がだんだん広がります。時間・値・補間方式は、下の「アニメーション」の欄で編集できます。書き出しでも同じ動きになります（字間が動く文字は、書き出しの準備にフレーム数ぶんの時間がかかります）。
- オーディオ（BGM・効果音・ナレーション）: 音量（0〜100%。はじめは 100%。つまみをドラッグしている間は、つまみの近くに今の音量が出ます）、フェード、開始位置、「動画の長さに合わせる」。タイムラインには波形と音量ラインが出ます。
- 音量キーフレーム: オーディオを分割しなくても、時間ごとに音量を変えられます。音量ライン（波形の上の線。上が 100%、下が 0%）をダブルクリックするとキーフレーム（丸い点）が増え、点を上下にドラッグで音量、左右にドラッグで音量が変わる時間を動かします。点の間は直線でなめらかにつながり、最初の点より前と最後の点より後は端の音量のままです。右クリックで削除できます。分割・複製・移動をしても、キーフレームは引き継がれます。プレビューにも書き出しにも同じ変化が反映されます。以前のプロジェクトで 100% を超えていた音量は、開くと 100% になります。
- 全画面表示: プレビューの右下の四隅のボタン（または F / F11 / 「表示」→「プレビューを全画面表示」）で、編集画面を一時的に隠して、映像だけを画面いっぱいに出します。選んでいる比率（16:9・9:16・1:1・4:5）は保ち、余った所は黒です。拡大率・位置・回転・エフェクト・アニメーションは、そのまま映ります。選択枠・ハンドル・ガイド線などの編集用の表示は出ません。
  - 全画面中は、Space で再生・一時停止、Esc / F / F11 / ダブルクリックで終了します。マウスを動かすと下に再生コントロール（再生・一時停止、再生位置、動画の長さ、シークバー、終了ボタン）が出て、しばらく動かさないと自動で隠れます（マウスのカーソルも隠れます）。
  - 終了すると、タイムラインのスクロール・ズーム、選択、再生位置、パネルの幅や表示、編集内容は、入る前のままです。全画面中は編集内容を変えません。映像を読み込み直すことはなく、再生中の映像と音声も続きます。
- 数値の調整: スライダーや数値の上にカーソルを合わせてホイールを回すと、値が増減します（上で増、下で減。数値が青くなります）。数値をクリックするか Tab で選ぶと、矢印キー（↑ → で増、↓ ← で減）で調整できます。押し続けると連続して変わり、Esc で選択をやめると、矢印キーは再びコマ送りなどに使えます。
  - 1 回の量は、位置 1px、拡大率 1%、回転 1°、不透明度 1%、音量 1%、キーフレームの時間 1 フレーム、秒数 0.1 秒です。Shift を押すと 10 倍、Alt を押すと 0.1 倍（拡大率・回転・不透明度・音量など小数に対応する項目だけ）になります。最小値・最大値は超えません。
  - ホイールや矢印キーで続けて変えたぶんは、元に戻す履歴の 1 回にまとまります（止まって少したつと区切ります）。直接入力できる欄（開始・長さなどの秒数、選んだキーフレームの時間・値）は、これまでどおり数値を打ち込めます。
  - パネルをホイールでスクロールしているとき、通り道の数値が勝手に変わらないよう、スクロールが止まって少したってから回したときだけ値が変わります。
- キーフレームアニメーション: 動画・写真・テキストの「位置 X / 位置 Y / 拡大率 / 回転 / 不透明度」を、時間で動かせます（テキストは「字間」も動かせます。音量は、上の音量キーフレームを動画の音声にも使えます）。
  - 右の設定欄の「アニメーション」で、項目ごとに ◆ を押すと、再生位置にキーフレームを置けます（もう一度押すと外れます）。◀ ▶ で前後のキーフレームへ移動できます。2か所以上に置いて値を変えると、間は自動で動きます。同じ時間・同じ項目には重ねて置けません。
  - キーフレームの編集は、すべて右の設定欄で行います（タイムラインにキーフレーム用の行は出ません。映像・テキストのバーに、キーフレームのある位置の小さな ◆ が出るだけです）。再生位置にキーフレームがある項目を触ると、その項目の「時間（フレーム）」「値」「補間方式」の入力欄が出て、キーフレームの時間と値を直接入力・ホイール・矢印キーで変えられます。時間を変えると、再生位置もそのキーフレームについていきます。
  - 補間方式は、リニア（初期設定）・イーズイン・イーズアウト・イーズインアウト・ホールド。設定欄の「補間方式」から選びます。
  - 「プリセット」を押すと、フェードイン / フェードアウト / 4 方向からのスライドイン / ズームイン / ズームアウト / 回転して登場 / ポップアップのキーフレームが自動で入ります。入ったあとも、キーフレームは自由に動かしたり、値を変えたりできます。
  - プレビューでは、選んだ映像・テキストの枠をドラッグして移動、四隅で拡大・縮小、上の丸で回転できます（Shift で 15 度刻み）。キーフレームのある項目は、「自動記録」がオンのとき、再生位置に自動でキーフレームが記録されます。オフのときは、◆ を押すまで増えません。
  - 設定欄の「コピー」「貼り付け」（Ctrl+Shift+C / Ctrl+Shift+V）で、再生位置にあるキーフレームを別の時間やクリップへ写せます。値と補間方式も保たれます。「すべて削除」でそのオブジェクトのキーフレームを消せます。
  - オーディオと音声つき動画の音量キーフレームも、右の設定欄の音量の ◆ で追加・削除でき、数値は再生位置の音量です（キーフレームのある時間で動かすと、そのキーフレームの値が変わります）。オーディオのバーの音量ラインと点は、これまでどおり操作でき、設定欄と同じものを編集します。
  - 動かしても、クリップの移動・複製・分割・長さの変更ではキーフレームの相対的な時間が保たれます（分割では分け目の値を前後に残します）。プレビューと書き出しは同じ計算です。キーフレームの無い既存のプロジェクトは、そのまま開けます。
- オーディオ一覧: 左の「オーディオ」タブの「オーディオを追加」で音声を登録しておくと、一覧に並びます。▶ で試聴でき（別の音を鳴らすと前の試聴は止まり、タイムラインの再生を始めても止まります）、タイムラインへドラッグすると、落とした位置に（半透明の予定表示つきで）何度でも置けます。タイムラインから消しても一覧には残ります。使っている素材は一覧から削除できません。登録はタブ（編集場所）ごとで、プロジェクトに保存されます。
- 画面: 比率 16:9 / 9:16 / 1:1 / 4:5、フレームレート 24 / 30 / 60fps。
- 書き出し: MP4（H.264 + AAC）。解像度 720p / 1080p / 4K、品質 高速 / 標準 / 高画質。
- 保存: プロジェクトを `.kvproj` ファイルに保存できます。変更するたびに自動でも保存しているので、アプリが途中で落ちても次に起動したときに復元できます（開いているタブをすべて元に戻します）。元に戻す / やり直しは 100 回までです。
- 編集場所（タブ）: 画面の上のタブバーで、いくつでも編集場所を増やせます。「＋」で追加、「×」で閉じる、タブをダブルクリックで名前の変更です。素材・タイムライン・テキスト・元に戻す履歴・再生位置・保存先は、タブごとに別々です。`.kvproj` を開くと新しいタブで開き、保存していない変更があるタブを閉じるときや、アプリを終了するときは、タブごとに保存するか確認します。書き出しは、いま表示しているタブの内容を書き出します。

- AI アシスタント: 頼んだとおりに編集したり、動画の画面を見てタイトル・テロップの案を出したりします（[AI アシスタント](#ai-アシスタント)）。

### AI アシスタント

右上の「AI」ボタン（Ctrl+Shift+A、または「表示」→「AI アシスタント」）で、画面の右端に AI アシスタントの欄が出ます。AI は、[AI サーバー](#ai-サーバー)にログインして使います（[AI を使う準備](#ai-を使う準備)）。AI サーバーが Amazon Bedrock のモデルに送ります。どのモデルを使うか（標準は Claude Sonnet 4.6。OpenAI の GPT-6.1 Sol なども使えます）は、AI サーバーで決めます（[server/README.md の「モデルを変える」](server/README.md#モデルを変える)）。

- 頼んで編集: 「1本目を2倍速にして」「最後の3秒に『ご視聴ありがとうございました』と入れて」「BGM を動画の長さに合わせて、最後はフェードアウトして」のように書いて送ると、AI がタイムラインを変更します。何をしたかは欄に 1 行ずつ出ます。
- タイトル案・テロップ案: 「タイトル案を考える」「テロップ案を考える」を押すと、AI が動画の画面を何枚か見てから案を出します。「追加」を押した案だけがタイムラインに入ります（テロップ案は「すべて追加」もできます）。
- 見比べて選ぶ: 見た目の決め方を AI に任せると（例: 「最初に『夏の思い出』とタイトルを入れて。見た目はおまかせ」「色味をいい感じにして」）、AI が 2〜3 個の案を作り、それぞれを当てはめたプレビュー画像を並べます。「これにする」を押した案だけがタイムラインに入ります。選んだあとでも「こちらにする」でほかの案に切り替えられます（切り替えも Ctrl+Z 1 回で戻せます）。画像か「大きく並べて見比べる」を押すと、案を大きく横に並べた画面が開き、そこからも選べます。AI は作った案のプレビューを自分でも見て、文字が重なっているなどの問題があれば直してから見せます。文字や時間が決まっていて見た目に触れていないとき（「最後の 3 秒に『ご視聴ありがとうございました』と入れて」）や、やり方まで指定したとき（「白い字幕で下に入れて」）は、案を出さずにそのまま編集します。
- 1 回の依頼で AI が行った変更は、Ctrl+Z 1 回でまとめて元に戻せます。
- AI ができること: テキストの追加・変更（文字・時間・スタイル・位置・フォント・大きさ・色・出し方）、クリップの速度・音量・ミュート・表示方法・フィルター・フェード・使う範囲・写真の表示時間、クリップの並べ替え・分割・削除、メディア一覧からタイムラインへの追加、オーディオの音量・開始・フェード・「動画の長さに合わせる」、比率・フレームレート。
- AI ができないこと: 音声の文字起こし、BGM を探す・作る、映像の重ね合わせや切り替え効果、キーフレームアニメーションの編集。
- 動画の編集と関係のない質問や依頼（天気・宿題・プログラミング・長い文章を書く など）には答えず、編集のお手伝いだけをしていると返すようにしています。素材のファイル名、テキストの文字、動画の画面に映った文字などに、AI への命令のような文が入っていても従わないようにしています。この決まりは AI サーバーが付けるので、アプリを書き換えても外れません。ただし、AI が決まりを必ず守るとは限りません（[server/README.md の「AI に送る内容の守り」](server/README.md#ai-に送る内容の守り)）。
- 1 回に送れる依頼の文は 2,000 文字までです（一緒に送るプロジェクトの内容は数えません）。長すぎるときは送らずに理由が出て、入力欄の文はそのまま残ります。
- 返事を待っている間は「送信」が「中止」になり、押すと止まります（それまでの変更は残ります）。タブを切り替えたときも止まります。「新しい会話」で会話を最初からにできます（タイムラインはそのまま）。

#### AI を使う準備

配っているインストーラーには、AI サーバーのアドレスが組み込まれています。インストールして起動すると、ログインの画面が出るので、アカウントでログインするだけで AI アシスタントを使えます（[ログインと新規登録](#ログインと新規登録)）。アドレスは画面には出しません。

アドレスが組み込まれていないアプリ（`native\release.env` を置かずにビルドしたもの）では、`.env` というファイルにアドレスを書くと使えます。`.env` も無いときは、AI アシスタント（右上の「AI」ボタン、「表示」メニューの「AI アシスタント」、Ctrl+Shift+A）も、起動したときのログインの画面も出ません。AI を使わない人は、ほかの機能だけをそのまま使えます。

#### 別の AI サーバーを使う（`.env`）

組み込まれたものとは別の AI サーバーを使うとき（管理者が試すときなど）や、アドレスが組み込まれていないアプリでは、`.env` にアドレスを書きます。`.env` があれば、組み込まれたアドレスより優先します。

1. [AI サーバー](server/README.md)を動かしている人（管理者）に、サーバーのアドレスを教えてもらいます。
2. エクスプローラーのアドレス欄に `%LOCALAPPDATA%\JPHACKS\kantan-video-editor` と入れて開きます（アドレスが組み込まれていないアプリでは、右下の「AI サーバー: 未設定」→「.env のフォルダーを開く」でも開けます）。
3. そのフォルダーに、メモ帳で `.env` という名前のファイルを作り、次の 1 行を書いて保存します（`https://ai.example.com` のところに、1 のアドレスを書きます）。メモ帳で保存するときは「ファイルの種類」を「すべてのファイル」にして、`.env.txt` にならないようにします。

   ```
   KANTAN_AI_SERVER=https://ai.example.com
   ```

4. アプリに戻ると、そのサーバーを使います（右下の「AI サーバー」に、つながったかが出ます）。起動し直す必要はありません（アプリに戻ってきたときに `.env` を読み直します）。組み込まれたアドレスに戻すときは、`.env` を消すか、`KANTAN_AI_SERVER=` のあとを空にします。

- `.env` は、アプリの exe のフォルダー → リポジトリの一番上（ソースから動かしているときだけ）→ `%LOCALAPPDATA%\JPHACKS\kantan-video-editor` の順に探し、`KANTAN_AI_SERVER` に値が書いてある最初の 1 つを使います。どれにも無ければ、組み込まれたアドレスを使います。同じ名前の環境変数があっても使いません。ソースから動かしているときは、リポジトリの一番上の `.env.example` をコピーして `.env` にしてもかまいません。
- `.env.example` には、アドレスを入れていません（リポジトリで公開しないため）。
- `https://` を省くと、インターネットのアドレスには `https://`、家の中のアドレスには `http://` を付けて使います（例: `192.168.1.10:8787` → `http://192.168.1.10:8787`）。末尾の `/` や、大文字・小文字の違いは気にしなくてかまいません。
- HTTP で書けるのは、同じ PC（`localhost`）、家の中のネットワークのアドレス（`192.168.…` など）、`.local` の名前、Tailscale のアドレス（`100.64.0.0/10`）だけです。それ以外を HTTP で書くと、パスワードを読まれないよう、ログインできないようにします（右下に「アドレスを確かめてください」と出ます）。
- `.env` は `.gitignore` で除外していて、git には入りません。アプリに API キーは要りません（Bedrock の API キーは、AI サーバーの `server\.env` にだけ書きます）。
- `.env` は UTF-8 でも UTF-16 でもかまいません（Windows PowerShell 5 の `>` で書いたファイルも読めます）。`#` で始まる行はコメントです。

#### ログインと新規登録

アドレスが決まっていれば、起動したときにログインの画面が出ます。サーバーのアドレスは出しません。AI サーバーにつながらないときだけ、画面の上にその理由が出ます（アドレスは入れません）。

- ログイン: 管理者が作ったアカウントか、自分で登録したアカウントのメールアドレスとパスワードでログインします。
- 新規登録: 「新規登録」のタブで、名前（空でもかまいません）・メールアドレス・パスワード（10 文字以上）を入れて「登録する」を押します。AI サーバーの決め方によって、次のどれかになります。
  - 管理者の承認が必要（はじめはこれ）: 「登録しました。管理者が承認すると、ログインできます」と出て、ログインの画面に戻ります。管理者が管理画面で承認すると、ログインできます。
  - すぐに使える: 登録すると、そのままログインします。
  - 受け付けない: 「登録する」は押せません。管理者にアカウントを作ってもらいます。
- 管理者が作った仮のパスワードでログインしたときは、続けて自分のパスワード（10 文字以上）を決めます（仮のパスワードは、もう一度入れなくてかまいません）。決めるまで AI は使えません。
- 「ログインしないで使う」で閉じると、AI を使わずに編集できます。あとから右下の「AI サーバー」か、AI の欄の「ログイン」でログインできます。
- ログインは暗号化して保存するので（`session.dat`。[データの保存場所](#データの保存場所)）、次に起動したときは、ログインの画面は出ずにログインしたままです。30 日使わないと切れます（使うたびに延びます）。切れていたときは、起動したときにログインの画面が出ます。
- 欄の上に、名前（ロール）と今月の残りのトークンが出ます。「アカウント」のメニューで、残りの読み直し・パスワードの変更・ログアウトができます。パスワードを変えると、ほかの PC でログインしたままのアプリはログアウトします。
- 今月の分を使い切ると「今月のトークンを使い切りました」と出て、送れなくなります。来月になるか、管理者が追加すると、また使えます。
- パスワードを忘れたときは、管理者に仮のパスワードを作り直してもらいます（メールでの再設定はありません）。

#### 右下の「AI サーバー」

ウィンドウの右下に、AI サーバーにつながっているかが出ます。30 秒ごとと、アプリに戻ってきたときに確かめます。

| 表示 | 意味 |
| --- | --- |
| 接続中（名前） | つながっていて、ログインしている（丸が黄色のときは、サーバーに Bedrock の API キーがなく、AI はまだ使えない） |
| ログインしていません | つながっているが、ログインしていない |
| パスワードを変えてください | 仮のパスワードのまま |
| 確認中… | 確かめている途中 |
| つながりません | サーバーが動いていない、またはネットワークにつながっていない。前に置いた Cloudflare などが、サーバーにつながらずにエラー（502・530 など）を返したときも（理由は、マウスを乗せると出ます） |
| アドレスを確かめてください | AI サーバーではないところにつながった、または HTTP で家の外のアドレスを書いている（`.env` のアドレスなら、マウスを乗せると直す `.env` の場所が出ます。組み込まれたアドレスなら、アプリを配った人に知らせるよう出ます） |
| データベースにつながりません | サーバーは動いているが、PostgreSQL につながっていない |
| 未設定 | アドレスが組み込まれておらず、`.env` にも `KANTAN_AI_SERVER` が無い |

- マウスを乗せると、つながらない理由や、ログインしているアカウントと今月の残りが出ます。サーバーのアドレスは出しません。
- 押すと、ログインしていなければログインの画面が出ます。ログインしていれば、アカウントのメニュー（今月の残り・つながりを確かめ直す・パスワードを変える・ログアウト）が出ます。
- 「未設定」のときに押すと、`.env` を置く場所と、「.env のフォルダーを開く」「.env を読み直す」が出ます。

#### AI に送るもの

依頼の文、プロジェクトの内容（クリップ・テキスト・オーディオの設定と、素材のファイル名）、AI が見ると決めた画面の画像（長い辺 768px の JPEG）を、AI サーバーを通して Bedrock に送ります。素材のファイルそのものは送りません。AI サーバーが残すのは使った量の記録（日時・アカウント・モデル・深さ・トークン数・かかった時間・エラーの文）だけで、依頼の文や画面の画像は保存しません。

#### 考える深さと使ったトークン

AI の欄の入力欄の上にある「考える深さ」で、AI が答える前にどれくらい考えるかを選べます。深いほど難しい依頼に強くなりますが、返事が遅くなり、考えた分のトークン（料金）も増えます。変えると、次に送る依頼から使われます。選んだものは `%LOCALAPPDATA%\JPHACKS\kantan-video-editor\settings.ini` に覚えておき、次に起動したときもそのままです。

| 選ぶもの | 動き |
| --- | --- |
| 自動（はじめはこれ） | 依頼ごとにアプリが決めます。手順がはっきりした編集や質問は「低」、案を出す・見た目を決める依頼（「案」「おまかせ」「いい感じ」などを含むもの）や長い依頼は「中」 |
| 低 | 考えるのは最小限。速く、トークンも少なめ |
| 中 | ほどほどに考える |
| 高 | いつもじっくり考える。難しい依頼向け |
| 最大 | いちばん深く考える。とても遅くなることがある |

- 依頼が終わるたびに、会話の欄に「使ったトークン: 入力 ○・出力 ○ ／ 考える深さ: ○」が出ます（「自動」のときは、決めた深さも出ます）。入力には、キャッシュから読んだ・キャッシュに書いた分も入ります（GPT は入力のほとんどを自動でキャッシュします。内訳は行にマウスを乗せると出ます）。出力には、AI が考えた分も入ります。欄の右下には、この会話の合計が出ます（「新しい会話」で 0 に戻ります）。料金はモデルごとに違うので、Bedrock の料金ページで確かめてください。
- 深さを変えられるのは Claude（Sonnet 4.6 以降）と OpenAI の GPT です。そのほかのモデル（Claude Sonnet 4.5 以前など）では「考える深さ」は選べず、モデルの標準のまま動きます。
- 考えた分も返事の長さの上限に入るので、上限（8192〜64000 トークン）は AI サーバーが、返事を待つ時間（3〜10 分）はアプリが、深さに合わせて広げます。
- 選べる深さは、アカウントの上限まで（管理者が決めます）です。ログインした直後は、管理者が決めた深さになります。サーバーでも、上限まで下げてから送ります。

## AI サーバー

AI アシスタントは、`server/` の AI サーバーを家の PC などで動かして使います。Bedrock の API キーはサーバーだけが持ち、使う人のアプリはメールアドレスとパスワードでログインします。アカウントごとに、AI を使える量（月のトークン）や考える深さを、ブラウザーの管理画面で決められます。使う人がアプリから自分で登録する「新規登録」も、管理者の承認制・すぐに使える・受け付けないから選べます。

- 起動は `server\start.cmd` をダブルクリックするだけです。Node.js は初回に `server\.runtime` へ自動でダウンロードします（システムには何も入れません）。
- start.cmd のウィンドウが開いている間は、`git pull` などでサーバーのファイルが更新されると、新しい中身を確かめてから、自動でライブラリを入れ直して起動し直します。
- 準備のしかた、管理画面、新規登録、トークンの上限、使うモデル、家の外からの使い方（HTTPS）などは、[server/README.md](server/README.md) にまとめています。

### 独自技術
#### ハッカソンで開発した独自機能・技術
* プレビュー: FFmpeg のライブラリで動画を直接デコードし（クリップごとに別スレッド）、音声の再生位置に映像を合わせて再生します。次のクリップは少し前から読み込んでおき、切り替わりで止まらないようにしています。
* 書き出し: タイムラインの内容から ffmpeg のフィルターグラフを組み立て、1 回の実行で MP4 にします。テキストは画像にしてから重ねます。素材ごとに違う色の規格（BT.601 / BT.709 など）は、そろえてからつなぎます。
* 色のフィルター、ぼかし背景、テキストの描画は、プレビューと書き出しで同じ計算になるようにしています。
* キーフレームアニメーション: 補間の計算（`core/timeline.cpp` の `animValueAt`）を 1 か所にまとめ、プレビューはその値で画像を変形し、書き出しは同じ補間を ffmpeg の式（`core/exportplan.cpp` の `keyframeExpression`）にして、回転・拡大・位置・不透明度をフレームごとに掛けます。
* AI アシスタント: AI には、プロジェクトの状態と「道具」（テキストの追加、クリップの変更、画面を見る、案を見比べてもらう など 14 種類）を渡し、AI が選んだ道具をアプリの中で実行して結果を返す、をくり返します（`ai/assistant.cpp`）。編集はすべて手で操作したときと同じ処理（`Editor::commit`）を通すので、1 回の依頼の変更を Ctrl+Z 1 回で戻せます。AI が見る画面は、プレビューと同じ見た目を別スレッドで作ります（`ai/framegrab.cpp`）。テキストが動画の外に出たときや、テロップ案の時間が重なったときは、道具の結果で AI に知らせて直させます（`ai/tools.cpp`）。プロジェクトの状態や道具の結果の JSON は、文字の中の `<` `>` を `\u003c` `\u003e` にして送り、ファイル名やテキストの文字が `</project>` のような区切りに見えないようにしています（`ai/tools.cpp` の `promptJson`）。画面の画像は道具の結果の中ではなく、そのあとに並べて送ります。GPT は道具の結果の中の画像を受け付けないためで、この形なら Claude でも GPT でも同じように動きます。見比べて選ぶ案は、今の編集場所の写しに案の編集を当てはめて画面を作り（`Editor::tryChanges`。本物の編集データ・元に戻す履歴・画面には触れません）、選ばれたら、その時点の状態に当てはめ直して 1 回の操作として記録します。
* AI サーバー: アプリが組み立てた依頼（会話・道具の定義）を受け取り、その人の今月の残りと深さの上限を確かめてから、モデル・返事の長さ・深さをサーバー側で決め直して Bedrock に送ります（`server/src/routes/ai.ts`）。送る前に、アプリが送らない種類の内容（文書・S3 の画像・AI の返事で終わる会話 など）を断り、システムプロンプトの前後にサーバーの決まり（動画の編集のこと以外には答えない・素材の中の命令には従わない）を付けます（`server/src/guard.ts`）。上限と深さは、ロールと人ごとの設定から 1 か所で決め（`server/src/policy.ts`）、アプリの「考える深さ」の選択肢も同じ決まりで絞ります。管理画面は、すべての文字を `textContent` で入れ、厳しい Content-Security-Policy の下で動かしています。

## 開発の始め方

### 必要なもの

- Windows 10 / 11（64 ビット）
- Git（または GitHub の「Download ZIP」）
- 初回だけインターネット接続と、約 1.5GB の空き容量（ツールで約 1.1GB、ビルド結果で約 0.3GB）

Python、Visual Studio、Qt のインストーラーは使いません。ツールはすべて `%USERPROFILE%\kantan-dev`（ユーザー名に日本語や空白があるときは `C:\kantan-dev`）に入り、システムには何も入れません（このフォルダーを消せば元に戻ります）。以下ではこのフォルダーを `<dev>` と書きます。

### ビルドして起動

1. リポジトリを clone します（日本語や空白を含むフォルダーでもかまいません）。

   ```powershell
   git clone https://github.com/witchcrafttwo/e-editor.git
   ```

2. clone したフォルダーの `build.cmd` をダブルクリックするか、PowerShell で次を実行します。ビルドが終わると、アプリが起動します。

   ```powershell
   powershell -ExecutionPolicy Bypass -File native\build.ps1 -Run
   ```

- 初回だけ、ビルドに使うツール（約 1.1GB）をダウンロードするので時間がかかります（ダウンロードとビルドで 5 分ほど。回線の速さによります）。2 回目からは、変更した分だけをビルドします。
- できたアプリは `native\dist\kantan-video-editor\kantan-video-editor.exe` です。同じフォルダーの DLL を使うので、exe だけを別の場所にコピーしないでください。

- ツールが足りないときは、先に `native\tools\setup.ps1` が自動でダウンロードします（Qt 6.8.3 の MinGW 版、MinGW 13.1、FFmpeg 8.1、CMake、Ninja、NSIS 3）。決まったファイルは SHA-256 で中身も確かめます。
- `build.ps1` はコンパイルしたあと、exe と動かすのに必要なファイル（Qt・FFmpeg・MinGW の DLL、ffmpeg.exe、ライセンス文）を `native\dist\kantan-video-editor\` に集めます。2 回目からは変更したファイルだけをコンパイルします。
- `-Run` はビルドのあとに起動します。`-NoDeploy` を付けるとコンパイルだけを行います。
- アプリを起動したままだと上書きできないので、閉じてからビルドしてください。
- `native\build\kantan-video-editor.exe` は DLL がそろっていないので、そのままでは起動しません。起動は `native\dist` の方で行います。
- ツールを別の場所に置きたいときは、環境変数 `KANTAN_DEV` に、日本語や空白を含まないフォルダーを指定します（例: `setx KANTAN_DEV D:\kantan-dev` のあと、ターミナルを開き直す）。ツールやフォルダーの場所が変わったときは、`native\build` を自動で作り直します。
- clone した場所に日本語や空白があると MinGW と Qt のツールが動かないので、ソースを `<dev>\work\` の中にコピーして、そちらでビルドします。エラーに出るファイルの場所もコピー先になりますが、直すのは clone した方のファイルです（ビルドのたびにコピーし直します）。
- ビルドがおかしくなったときは、`native\build` フォルダーを消してからやり直します。
- OneDrive で同期しているフォルダーに clone すると、ビルド結果（約 300MB）まで同期されます。同期しない場所に置くのがおすすめです。

### インストーラーを作る

```powershell
powershell -ExecutionPolicy Bypass -File native\installer\build-installer.ps1
```

ビルドもまとめて行い、`native\dist\kantan-video-editor-cpp-<バージョン>-setup.exe` を作ります（圧縮に数分かかります）。

### 配る（Releases に置く）

使う人には、ビルドしてもらうのではなく、インストーラーを配ります。exe や DLL はリポジトリに入れていないので（FFmpeg の DLL が GitHub の上限の 100MB を超えるため）、GitHub の Releases に置きます。

1. バージョンを上げます（[開発メモ](#開発メモ)の 2 か所）。
2. `native\release.env` に AI サーバーのアドレスを書きます（[下の「AI サーバーのアドレスを組み込む」](#ai-サーバーのアドレスを組み込む)。一度書けば、次からはそのままでかまいません）。
3. 上の[インストーラーを作る](#インストーラーを作る)で setup.exe を作ります。作ったら、`.env` の無い PC（または `.env` をよけた状態）で一度インストールして、起動するとログインの画面が出て、AI が使えるか確かめます。
4. GitHub のリポジトリの「Releases」→「Draft a new release」で、`v<バージョン>` のタグを作り、setup.exe を添付して公開します。

- `native\dist\kantan-video-editor\` のフォルダーを ZIP にして配ることもできます（展開して `kantan-video-editor.exe` を開くだけで動きます）。そのときも exe だけを抜き出さず、フォルダーごと配ります。
- FFmpeg が GPL v3 なので、配るときは[ライセンス](#ライセンス)の条件に従ってください（Releases にソースコードを添えるか、このリポジトリのそのバージョンのタグを案内します）。

#### AI サーバーのアドレスを組み込む

使う人が `.env` を書かなくても AI を使えるよう、配る exe に AI サーバーのアドレスを組み込みます。

1. `native\release.env.example` をコピーして、同じフォルダーに `release.env` という名前で置きます（`.gitignore` で除外しているので、git には入りません）。
2. `KANTAN_AI_SERVER=` のあとに、AI サーバーのアドレスを書きます（例: `KANTAN_AI_SERVER=https://ai.example.com`）。
3. いつもどおりビルドするか、インストーラーを作ります。`build.ps1` が「AI サーバーのアドレスを exe に組み込みます」と出せば、組み込まれています。

- アドレスは、exe を文字で眺めても見えないよう、ビルドのたびに作る鍵と混ぜたバイトの並びで埋め込みます（`build\generated\kv_embedded_server.h`。git には入りません）。アプリは画面にもアドレスを出しません。
- ただし、秘密にはなりません。アプリは実際にそのサーバーと通信するので、通信を見る道具（リソース モニター・Fiddler など）や exe の解析で、接続先は分かります。守りは、ログイン・トークンの上限・新規登録の承認制に任せてください（家の外に出しているサーバーで、新規登録を「すぐに使える」にしないでください）。家の PC の IP アドレスを知られたくないときは、Cloudflare Tunnel などのドメインのアドレスにします。
- 組み込めるのは、`https://` のアドレスか、家の中・Tailscale のアドレスだけです。HTTP で家の外のアドレスを書くと、ビルドを止めます（配ったあとでは直せないため）。
- `release.env` が無い・値が空のときは組み込みません。インストーラーを作るときは、警告が出ます。
- 使う人の PC に `.env` があれば、そちらを優先します（[別の AI サーバーを使う](#別の-ai-サーバーを使うenv)）。
- Bedrock の API キーは、組み込みません（キーは AI サーバーの `server\.env` にだけ置きます）。exe に入れたものは取り出せるためです。

### VS Code などの IDE で開くとき

CMake の設定を `build.ps1` と同じにします。

| --- | --- |
| CMake | `<dev>\cmake\bin\cmake.exe` |

### 開発メモ

- 新しい `.cpp` / `.h` を作ったら、`native/CMakeLists.txt` の `SOURCES` に追加します。
- AI サーバーの開発のしかた（テスト・データベースの変更・Node.js の版）は、[server/README.md](server/README.md#テスト開発) にあります。
- アイコンを足すときは、[Lucide](https://lucide.dev) の SVG を `native/resources/icons/` に置いて `native/resources/app.qrc` に 1 行足し、`theme::icon(QStringLiteral("名前"))` で使います。
- 画面の文言は、ソースに日本語で直接書いています（翻訳ファイルは使っていません）。
- バージョンを上げるときは、`native/CMakeLists.txt` の `project(... VERSION ...)` と `native/resources/app.rc` の 2 か所を変えます。インストーラーのファイル名は CMakeLists.txt のバージョンから付きます。
- 書き出しに使う ffmpeg.exe は、アプリと同じフォルダー → 環境変数 `KANTAN_FFMPEG` → PATH の順に探します。
- ffmpeg に渡しているコマンドを確かめたいときは、アプリを閉じてから `$env:KANTAN_DEBUG_EXPORT = '1'; .\native\dist\kantan-video-editor\kantan-video-editor.exe` で起動します。書き出すたびに `%TEMP%\kantan-last-export.txt` に保存されます。
- 日本語を含む `.ps1` は UTF-8（BOM 付き）で保存します。Windows 標準の PowerShell 5.1 は、BOM がないと文字化けして正しく動きません。
- ビルド結果、exe・DLL、動画は `.gitignore` で除外しています。GitHub は 100MB を超えるファイルを受け付けず、FFmpeg の DLL はそれより大きいためです。

## データの保存場所

| 内容 | 場所 |
| --- | --- |
| 自動保存（全タブ分） | `%LOCALAPPDATA%\JPHACKS\kantan-video-editor\autosave.kvproj` |
| サムネイル・波形・写真のキャッシュ | `%LOCALAPPDATA%\JPHACKS\kantan-video-editor\cache\` |
| AI サーバーのアドレス（`KANTAN_AI_SERVER`） | 配る exe に組み込み（ビルドするときの `native\release.env` から）。別のサーバーを使うときは、`%LOCALAPPDATA%\JPHACKS\kantan-video-editor\.env`（開発中はリポジトリの一番上の `.env` も） |
| AI サーバーのログイン（暗号化） | `%LOCALAPPDATA%\JPHACKS\kantan-video-editor\session.dat` |
| AI サーバーのアカウント・使用履歴 | サーバーの PC の PostgreSQL（設定は `server\.env`） |
| プロジェクトの保存先（最初に開く場所） | ドキュメント |
| 書き出しの保存先（最初に開く場所） | ビデオ |

- キャッシュは消しても、次に開いたときに作り直されます。
- アンインストールしても、自動保存とキャッシュは残ります。いらなければ `%LOCALAPPDATA%\JPHACKS` を消してください。
- アプリはレジストリには何も書きません。レジストリに書くのはインストーラーだけで、`.kvproj` の関連付けとアンインストールの情報です。`.env` は読むだけで、アプリが作ったり書き換えたりはしません。AI の欄で選んだ「考える深さ」は、`%LOCALAPPDATA%\JPHACKS\kantan-video-editor\settings.ini` に書きます。
- AI サーバーにログインすると、ログインの印を `session.dat` に書きます。Windows の DPAPI で暗号化していて、その PC のその Windows ユーザーしか読めません。印は、ログインしたサーバーにだけ送ります（`.env` のアドレスを別のサーバーに変えると、そのサーバーでログインし直します。元のアドレスに戻すと、前のログインをまた使います）。ログアウトすると消えます。
- アンインストールしても `.env` は残ります。いらなければ、ファイルを消してください。

## できないこと・注意点

- ビデオのトラックは 1 本だけです。クリップは前から順に隙間なく並び、重ねたり切り替え効果を入れたりはできません（フェードは黒へのフェードです）。
- キーフレームアニメーションで映像を小さくしたり動かしたりしたとき、空いたところは黒です（下に別の映像は出ません）。不透明度を下げると黒に近づきます。
- テキストの拡大率は画像の拡大で行うため、大きくするほど輪郭がやわらかくなります（文字サイズを変えたいときは「サイズ」を使います）。
- 補間方式（イーズイン / イーズアウトなど）のある区間の途中で分割すると、分け目の値は同じですが、区間の曲線の形はすこし変わります（リニアとホールドは変わりません）。
- 書き出しで位置を動かすとき、重ねる位置は 1 画素（動画の色の都合で 2 画素）単位です。回転や不透明度をキーフレームで動かすと、書き出しに少し時間がかかります。
- プロジェクト ファイルには素材の場所（フルパス）を記録しています。素材を移動したり別の PC で開いたりすると「見つかりません」になり、場所を指定し直す機能はまだありません。
- HDR の動画は色を変換しないので、色が薄く見えます。
- 書き出せるのは MP4（H.264 + AAC）だけです。
- AI アシスタントは、インターネット接続と、AI サーバーのアカウントか Bedrock の API キーが必要です。AI は間違えることがあるので、変更は必ずプレビューで確かめてください（Ctrl+Z で戻せます）。AI は音声を聞けないので、話している内容に合わせた字幕は作れません。
- AI サーバーのトークンの上限は、1 回の依頼で少し超えることがあります（超えたら次の依頼から断ります）。パスワードを忘れたときの、メールでの再設定はありません（管理者が仮のパスワードを作り直します）。
- インストーラーには署名がありません（SmartScreen の警告が出ます）。
- Windows 専用です。
